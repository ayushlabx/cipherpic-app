🔐 CipherPic

Offline-First Personal Privacy Vault

CipherPic is a privacy-focused application designed to keep personal and sensitive information securely stored on the user's device.

The project focuses on privacy, local encryption, security, and user control.

«Lock it. Hide it. Own it.»

---

📱 Project

CipherPic is designed as a personal privacy vault for storing and protecting sensitive digital information, including:

- 📷 Photos & Videos
- 📄 Documents
- 📝 Notes
- 🔐 Passwords & Sensitive Data
- 🗂️ Private Files
- 📋 Sensitive Clipboard Data

The core philosophy is simple:

Your private data should remain under your control.

---

🔐 Security

CipherPic uses modern security mechanisms including:

- AES-256-GCM encryption
- Per-image encryption keys
- Argon2id-based PIN protection
- Device key protection
- Biometric re-authentication
- Secure vault locking
- Screenshot/capture protection
- Lockout protection
- Encrypted trash
- Secure import/export
